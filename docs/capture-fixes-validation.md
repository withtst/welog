# 动态图、回放坐标与滚动步长修复验证

验证只使用已保存的截图、模拟滚动源和 Qt 离屏测试，没有操作真实微信窗口。

## 修复行为

- 稳定检测比较整个时间窗口内的布局。变化区域按原生像素分块，默认最多屏蔽有效面积的 12%；必须有足够的静止匹配块支撑判断。全页滚动、稀疏文字缓慢移动和大范围动画仍不能通过。局部动画遮罩记录在帧动作元数据中，并用于后续位移校正和回放。
- 真实采集回放以源确认记录决定坐标资格。诊断截图、未提交或源采集未接受的帧保留供查看，但不会设置原点、推进高度或更新检查点。排除标记可跨多次回放保留。
- 滚动从一个标准事件开始，逐步调整每批事件数量，默认单事件 120 单位、事件间隔 35 ms、最多 8 个事件。根据近期实测速率保守规划步长，失败后回退恢复重叠并重新标定。停止请求可中断批次。
