# 窄小动图片段与边缘布局验证

## 本次证据

原采集确认 70 帧，在 −14994px 后记录稳定超时：动态分块覆盖约 13.24%，媒体支持率约 99.42%，原因是 `motion_outside_media`。保留了 71 张图，其中最后一张为未确认诊断帧。

诊断图最上方只剩约 26×13px 的红色动图片段。其前景与视口的中性边线连在一起，轮廓变成整窗范围，被常规媒体过滤排除；内部的有色连通部分仍可单独定位。这解释了“覆盖率很高但仍超过媒体外像素上限”的触发路径，修复没有提高媒体外任意运动的额度。

## 稳定检测修复

`detect_bubbles(include_small_edge_media=True)` 仅供时间稳定检测启用。它额外检查靠近上下边缘的有色连通部分，要求位置、面积和尺寸达到阈值，并加少量描边余量；默认消息检测不启用该选项，因此不会把图像边缘的脚、尾部等另存为消息。媒体之外的正文运动仍按原保护规则拒绝。日志补充 `outside_pixels`。

媒体定位还会先临时切断中性视口边线，保留整个触边媒体区域，避免只找到帽子而漏掉内部眼睛/嘴部；有色小片段定位作为补充。该处理仅影响时间检测辅助区域，不改原图或消息检测结果。

## 跨屏证明

该布局还存在头像重复、唯一正文已接近视口外的问题。新增保守回退：

- 从顶部/底部的小纹理块提出位移候选，匹配相关系数至少 0.97；排除视口自身的外侧 4px 边线。
- 候选不能仅靠一个边缘块成立。实际重叠区中至少 6 个独立小块须吻合，匹配比例至少 85%，横向和纵向均须有至少 48px 跨度。
- 仍须通过原像素误差、75% 覆盖率、方向和最小重叠校验。多个不同位移成立或重复峰过多时拒绝。
- 布局回退排除已定位的内容媒体区域，保留头像列作为空间证据，避免把动图的暂时静止相位当作固定布局；这是当前浅色私聊布局的回退，不代替未知界面的校准。
- 几何回放和生产 MotionTracker 使用同一个边缘布局验证器；失败原因保存在诊断字段。

这不同于时间上的原位置比较：跨屏候选必须由两张图的真实重叠布局自证，不使用滚轮请求量计算高度。

## 验证与范围

- 合成窄片段与边框相连的场景：旧策略拒绝，新策略通过；移动正文、非触边小色块继续拒绝，默认消息检测不新增片段消息。
- 真实诊断图可定位漏掉的顶部片段。以原图为背景生成受控动画，媒体支持恢复完整；原始 PNG 校验和未变，没有生成新的原采集图。
- 相邻原图的独立空间验证得到 −201px；受控动画输入通过完整“稳定检测 → 配准 → 累计位置”流水线。
- 包含旧视口中某个放大动图暂时冻结的控制样本；不依赖每个动图在所有采样间都发生变化。
- 反方向、无关画面及固定边框/浮层、缩放、周期重复歧义均有反例。
- 原始 71 帧归档按原确认资格回放：70 帧确认、1 帧诊断排除、0 配准失败，累计仍为 −14994px。

没有改写原任务的确认资格、数据库或检查点，也没有操作微信窗口。失败时间窗只保留了最后一张诊断图，没有该时间窗的完整连续采样，所以受控动画不是对原时间序列的精确重建。新的空间候选也不会据此自动追认原诊断帧。

最终全量测试：292 项通过、4 项缺失私有输入跳过；不含私有数据的公开副本：286 项通过、10 项跳过。覆盖薄触边片段、边框连通、放大表情内部部件、运动反例及冻结相位；本地验证报告保存在忽略的 `runs/edge-fragment-validation/` 下。
