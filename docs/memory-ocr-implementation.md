# 内存 OCR 流水线实现与离线验证

## 已落地的默认行为

实时 `run_capture`、GUI 和 CLI 现在默认走 `MemorySession`。不保存原图、气泡裁剪、跨缝图或诊断图；异常路径也只记录尺寸、原因和稳定性元数据。旧的 `Archive` 仅供历史格式及显式合成测试使用，实时控制器不再导入它。

输出为元数据 JSONL、SQLite 消息库、消息 JSONL 和不含图像的 HTML 报告。GUI 不再自动调用依赖 PNG 的历史回放。历史回放改成 `ReferenceArchive`，只引用原来已存在的图像，重复回放不再复制图片。

`RapidOcrAdapter` 接受 numpy BGR 数组；模型在单 OCR 工作线程中懒加载、复用，使用 CPU ONNX Runtime 和 PP-OCRv6 small。当前线程配置以逐页确认、背压优先：完成当前页的 OCR 和连续性计算后再发下一批滚轮事件，不会让未处理页面无限积压。

## 实现模块

| 模块 | 职责 |
|---|---|
| `frame_pool.py` | 64 MiB 默认受管图像额度、FrameLease 所有权和释放 |
| `recognition.py` | 数组 OCR、浅色私聊气泡/媒体候选、独立头尾状态 |
| `motion.py` | 文字锚点、原生像素细校正、模板和静态特征辅助 |
| `assembler.py` | 几何区间识别消息身份、跨屏文字行合并和修复 |
| `pipeline.py` | 有界单工作线程、滚动边界条带与跨缝重 OCR |
| `message_store.py` | SQLite 流式消息/文字行/观察记录及文字报告 |
| `session.py` | 不接受图像载荷的帧、配准和检查点日志 |
| `controller.py` | 采集背压、单方向输入、原位重试及异常释放 |

没有迁入两个外部项目的实现或依赖。新增算法和接口是项目内独立实现，外部源码仍只作为研究快照保存。

## 气泡与跨屏消息

- 不使用 40% 或 85% 视口高度过滤长气泡。
- 顶部和底部分别记录 visible/clipped；结构支持 uncertain。OCR 状态与几何状态分离。
- 媒体正文遮罩和动态图运动遮罩独立：静态图片可辅助位移，但不把其内部文字作为聊天正文。
- 消息 UUID 根据物理气泡观察建立，不按发送者加正文哈希去重；完整的重复回复保持独立。
- SQLite 保存文字行的全局位置。跨屏重识别优先使用完整行替换裁断行，不因原裁断行置信度较高而保留残字。
- 上下边界条带独立复制，按已确认高度裁掉重叠后构造小范围拼接图；该图仍只在内存，识别后释放。
- 三屏以上气泡以连续观察和文字行组装，不创建无限长图片。未闭合边界、低置信度或 OCR 失败保留 partial/ocr_failed。

文字框的定位可能存在像素抖动，因此文字锚点位移还会在邻近原生像素范围细校正。本次真实样本曾出现 1 px 累积偏差，增加细校正后六帧累计回到 -1041 px。

整图模板失败不再触发反向输入。程序先原位重试，无法证明连续时以 `continuity_unconfirmed` 停止。静态特征备用路径要求足够内点、近似纯纵向平移，并验证重叠内容，不直接信任一个特征匹配结果。

## 内存和错误处理

应用持有的图像、灰度参照、条带和显式工作区受字节额度约束；OCR 队列也有容量上限。停止请求可在滚轮批次之间及等待 OCR 时检测，当前模型调用使用的图像不会被提前销毁；它完成后归还额度，之后不再发滚轮事件。

释放后模型运行库可能保留内存池。报告中的 `image_memory_peak_bytes` 是受管图像额度峰值，不是进程 RSS；模型权重、推理内部工作区及采集后端原生缓冲另计。

异常消息不会把第三方 OCR 的异常正文原样写入日志，以免夹带聊天内容。OCR 失败仍保留可定位的气泡候选；几何不确认的观察保存在 `observations.jsonl`，不伪装成已确认消息。

## 离线验证结果

完整测试：**90 passed**。没有运行真实微信、原生滚轮测试或截图测试。

主要回归包括：

- 同时拦截 OpenCV 图片写入/编码、PIL 图片保存、临时文件和 numpy 图片数组保存，验证正常、稳定超时、OCR 异常及额度不足路径。
- 三屏消息双向组装，重复的“好”保留，“开会/开会取消”不合并。
- 实际流水线通过边界重 OCR 修复被裁断文字；跨缝图没有写盘。
- 原先动图失败样本的静态特征备用配准得到 -300 px，无窗口输入。
- 模拟文字框 1 px 抖动仍得到正确原生位移。
- 一千次条带替换内存保持固定，完成后额度归零；慢 OCR 队列背压不丢图；批次中途和 OCR 进行中的停止不发下一次滚轮。
- 历史归档的方向、恢复帧双向搜索、未确认帧排除和 -22681 px 真实归档回归保持通过。

## 当前适用范围

基线针对已校准的浅色私聊气泡。群成员昵称、复杂引用、文件/语音/红包和其他主题没有宣布完整支持；不确定媒体使用占位。实际模型字符准确率、复杂卡片分类及长期真实模型 RSS 平台仍需要更多离线标注样本验证。

重现命令：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools/validate_memory_pipeline.py --source runs/pointer-20261116-204033-bf2111/capture --output runs/memory-validation-new --frames 6
```

输出目录须为空。验证工具禁止图像写入，不调用窗口 API。启动新版 GUI 后使用的是新流程，原来的截图归档不会自动删除。
